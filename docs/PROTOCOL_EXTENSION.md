# Совместимость v2 и сервисное расширение v1

Исходный внешний контракт сохранён в `ORIGINAL_PROTOCOL_README.md` без изменений.
Упоминания ESP32 в нём для этого проекта относятся к Arduino Mega, кроме Wi-Fi/UDP:
на Mega реализован только UART. Размер ≤384 байт вместе с LF, 115200 8N1.

## Ручное наведение

Отдельного типа команды не требуется. Каждые 40 мс Python отправляет DRONE_SIM v2
со всеми 17 полями, нулевой скоростью, mode=RUN и виртуальной целью R=100 м:

```
x = R*cos(EL)*sin(AZ)
y = R*cos(EL)*cos(AZ)
z = R*sin(EL)
```

AZ/EL передаются явно и сохраняют ручной AZ даже при EL=90°. В режиме сопровождения
геометрически неопределённый AZ остаётся null/false, как требует основной протокол.
В ручном режиме sim_ms — время модели, оно может стоять; host_ms всегда идёт.

## ANTENNA_CONTROL v1 (ПК → Mega)

Независимое сервисное расширение. Оно не переопределяет DRONE_SIM или ANTENNA_STATE.
Сервисный seq имеет собственный uint32-счётчик, независимый от seq телеметрии.

```json
{"protocol":"ANTENNA_CONTROL","version":1,"seq":0,"action":"CALIBRATE","az_mech_deg":0}
```

Все показанные поля обязательны. `az_mech_deg` — конечное число, механический
развёрнутый угол (не нормализованный ENU). Применяется только при отключённом разрешении
приводов, включённом MECHANICS_CONFIGURED и попадании в безопасный диапазон.
Калибровка счётчика AZ округляется до целого полушага; если округление выйдет за предел,
команда отклоняется. Оператор физически устанавливает EL_INITIAL до калибровки.
Повторная калибровка при armed=true отклоняется, сначала нужен DISARM.
Калибровка не обновляет watchdog телеметрии и не меняет source_seq.

```json
{"protocol":"ANTENNA_CONTROL","version":1,"seq":1,"action":"DISARM"}
```

Останавливает дальнейшее движение и запрещает новые цели до калибровки, удерживая
счётчик шагов и последнюю PWM. Не отключает питание. Работает и при STALE.

## ANTENNA_ACK v1 (Mega → ПК)

```json
{"protocol":"ANTENNA_ACK","version":1,"seq":0,"ok":true,"reason":"OK"}
```

`seq` — эхо сервисного seq, не seq ANTENNA_STATE. `ok` — bool, reason — ASCII string.
Python повторяет одну неподтверждённую команду с тем же seq каждые 150 мс, максимум
четыре отправки. Это не повторяет движение: Mega повторно возвращает сохранённый ACK
для последнего сервисного seq, не применяя команду заново. Одновременно выполняется
только один сервисный запрос. Старые сервисные seq игнорируются.

Отсутствие ACK означает «результат неизвестен», а не «команда не применена».
При таком результате проверьте поток и состояние МК; не считайте калибровку подтверждённой.
Сервисные команды не учитываются в показателе tx_sent телеметрии.

## Необязательные поля ANTENNA_STATE v2

- `reason`: `OK`, `CONFIG_REQUIRED`, `UNCALIBRATED_OR_ARMED`, `AZ_UNREACHABLE`, `AZ_LIMIT_STOP`.
- `rx_bad`: число отклонённых по формату/переполнению очереди кадров.
- `rx_ovf`: число переполненных строк.

Два счётчика опускаются, если ответ иначе не поместится в 384 байта. Обязательные
12 полей не удаляются. Счётчики отражают кадры, прошедшие UART-задачу; отбрасывание
старых/дублирующихся DRONE_SIM выполняется контроллером и не обновляет watchdog.

`cmd_az_deg` после принятой цели — достижимая цель с учётом квантования шага;
при недостижимости/невалидности оси азимут останавливается, cmd_az становится углом удержания
по оценке. `cmd_el_deg` — конечная ограниченная цель контроллера серво; импульсы идут к ней
с ограничением скорости. После STALE/DISARM — последний выданный угол PWM.
Ни одно из этих значений не означает измерение. act_* всегда null без датчиков.

STATUS: STALE при отсутствии свежей телеметрии >250 мс, иначе FAULT при отсутствии
разрешения/недостижимой цели, иначе NO_FEEDBACK. TRACKING не используется без датчиков.
Один повреждённый кадр отклоняется целиком; сам по себе он не отменяет предыдущую команду.

## Порядок и перезапуск

Сравнение seq: `0 < uint32(new-old) < 2^31`. У обоих направлений свои счётчики.
Сброс счётчиков не определяется эвристикой по тайм-ауту. При новом процессе ПК сбросьте
Mega, если открытие USB-порта не сделало это автоматически; затем калибруйте заново.
После полного оборота uint32 последовательность продолжается нормально.
