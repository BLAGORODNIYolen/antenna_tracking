# Подключение

| Узел | Arduino Mega / соединение |
|---|---|
| ULN2003 IN1 | D22 |
| ULN2003 IN2 | D23 |
| ULN2003 IN3 | D24 |
| ULN2003 IN4 | D25 |
| 28BYJ-48 5 В | Штатный 5-контактный разъём платы ULN2003 |
| ULN2003 V+ | Внешние стабилизированные +5 В |
| ULN2003 GND | Общая земля |
| SG5010 signal | D9 |
| SG5010 питание | Внешние стабилизированные +5 В и GND |
| Mega GND | Общая земля источника приводов |
| Mega USB | USB компьютера: питание логики и Serial |

Не соединяйте внешние +5 В с выводом 5V Mega при питании Mega по USB без отдельного
решения развязки питания. Приводы не питаются от платы. Полярность и назначение
проводов сверяйте с фактическим сервоприводом; не определяйте их только по цвету.
На ULN2003 проверьте перемычки питания и подключение общего вывода защитных диодов.

Питание 12 В не требуется. Нельзя подавать его на эти 5-вольтовые приводы.
Источник выбирается по сумме измеренных пиковых токов с запасом; практический исходный
ориентир для испытаний — качественный 5 В / 3 А, но это не подтверждённый ток вашего SG5010.
Установите конденсатор рядом с сервоприводом и аппаратный выключатель питания приводов.

По USB не нужен дополнительный TTL-адаптер. При внешнем USB-UART используйте
совместимые с Mega логические уровни 5 В, перекрестные TX/RX и общую землю.
Прошивка использует Serial (D0/RX0, D1/TX0); встроенный USB-UART и внешний адаптер
не должны одновременно передавать на эти выводы.

Нумерация аргументов GyverStepper отличается от нумерации входов платы:
в исходниках передано IN1, IN3, IN2, IN4 — провода физически остаются подключены по таблице.
Направление уточните небольшим перемещением и параметром AZ_REVERSE.

Механические пределы программные. Они защищают только при правильной калибровке,
коэффициенте передачи и отсутствии пропущенных шагов. Для независимой защиты нужны
аппаратные концевики/цепь остановки, которые в данном составе не заявлены.
