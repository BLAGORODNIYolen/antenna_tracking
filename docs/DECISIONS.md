# Расхождения и принятые решения

1. **ESP32/UDP в README против Mega/UART в DOCX.** Целевая аппаратная платформа только
   Mega 2560, как указано пользователем. UDP оставлен в Python исключительно для
   локального mock и тестов, сетевой прошивки нет.
2. **DOCX исключает симулятор полёта.** Явный запрос пользователя и README имеют приоритет:
   реализованы ручной полёт, прямая, окружность и независимая ручная антенна в одном GUI.
3. **Ручной режим.** Применён способ из DOCX: корректный DRONE_SIM v2, виртуальная цель
   R=100 м, переданные углы заданы явно. Отдельный SET_ANGLE и изменение версии v2 не нужны.
4. **Калибровка и блокировка отсутствуют в v2.** Добавлены независимые сообщения
   ANTENNA_CONTROL/ANTENNA_ACK v1. Существующие поля v2 сохраняются без переопределения.
5. **EL [0,90] в разделе координат и [-90,90] в протоколе.** Парсеры следуют протоколу;
   полёт GUI ограничен z≥0, ручной EL допускает [-90,90], прошивка ограничивает физический EL
   параметрами конфигурации. На Arduino возвращается реально принятая ограниченная цель.
6. **Механические границы и PWM неизвестны.** Примеры [-90,+90] и 1000…2000 мкс не признаны
   характеристиками механизма. По умолчанию приводы программно запрещены до настройки config.h.
7. **Угол без датчика.** Счётчик шагов не отправляется как act_az. Последняя PWM-команда
   не отправляется как act_el. Физические измерения остаются null; NO_FEEDBACK — нормальный статус.
8. **FreeRTOS 15 мс против частого шага и UART.** Задачи равноприоритетные, добровольно
   переключаются каждый проход; ожидание целого RTOS-тика не используется для шагания.
9. **Неопределённый AZ/недоступная цель.** Азимут останавливается в текущей оценке,
   EL при этом может продолжать движение. Это разрешённая ТЗ стратегия безопасного удержания.
10. **Повторный запуск ПК.** В v2 нет session_id. Счётчики сохраняются при reconnect в рамках
    приложения; новый процесс требует сброса Mega, если USB не сбрасывает его автоматически.
    Старый seq не принимается даже после STALE, чтобы отложенный пакет не откатывал цель.
11. **Строгий профиль JSON на AVR.** Обязательные поля v2 полностью поддерживаются.
    Дополнительные плоские скалярные поля игнорируются. Вложенные дополнительные объекты,
    JSON-escape в именах/строках и более 32 полей отвергаются (не используются штатным Python).
    Все штатные сообщения ASCII и не требуют escape. Дубликаты ключей и хвост после JSON запрещены.
12. **Аппаратная остановка.** DISARM не отключает питание: удерживает шаговик и последнюю PWM.
    После DISARM требуется калибровка. Для аварийного снятия питания предусмотрите физический выключатель.

Документация использованных компонентов:
- https://github.com/feilipu/Arduino_FreeRTOS_Library — задачи, WDT tick, поддержка Mega.
- https://arduinojson.org/v6/api/json/deserializejson/ — парсер.
- https://arduinojson.org/v6/api/staticjsondocument/ — статическая память JSON.
- Исходники Servo и GyverStepper, предоставленные пользователем, включены в firmware/lib.
